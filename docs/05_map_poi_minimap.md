# 05. 맵 · 주요 장소(POI) · 미니맵

## 5.1 월드 구조

### 좌표계 & 스케일
- 1 언리얼 유닛 = 1 cm. 게임 내 "1 km" = 100,000 u.
- 배틀 맵: **8 km × 8 km × 12 km(고도)** — 지상 게임과 달리 **고도 축이 가장 넓은 것**이 이 게임의 특징입니다.
- 레이스 맵: 폭 3 km × 길이 12~18 km × 고도 12 km의 회랑(corridor) 형태.

### 고도 레이어 (전 맵 공통 규약)

| 레이어 | 고도 | 이름 | 역할 |
|---|---|---|---|
| L0 | 0 ~ 1,500 m | **협곡층 (Canyon)** | 최단 경로, 고위험 지형 |
| L1 | 1,500 ~ 5,000 m | **운해층 (Cloud Sea)** | 표준 경로, 시야 제한 |
| L2 | 5,000 ~ 9,000 m | **정거장층 (Skyport)** | **POI 전용층**. 구름 위, 시야 개방 |
| L3 | 9,000 ~ 12,000 m | **성층권 (Stratos)** | 우회로. 엔진 출력 감소, 적 조우 없음 |

> **"주요 장소들은 구름 위에 있다"** 는 원 요구사항은 L2에 대응합니다. 이 층은 운해 위에 떠 있어 **아래 구름 바다가 보이고, POI가 멀리서도 랜드마크로 식별**되도록 조명·안개를 설계합니다. 게임의 대표 스크린샷이 나오는 층이므로 아트 우선순위 1순위입니다.

## 5.2 주요 장소 (POI) 스펙

3종 POI는 **모든 모드에 동일하게 존재**합니다 (원 요구사항).

### 공통 구조
- 구름 위에 떠 있는 **부유 플랫폼**(직경 300~500 m), 중앙에 통과형 **격납 링(Docking Ring)**.
- **이용 방식**: 링을 통과하며 속도를 200 u/s 이하로 유지 → 3초 카운트다운 후 상점 UI 오픈.
  - **완전 정지·착륙 불필요.** 비행 게임에서 착륙 조작을 요구하면 접근성이 무너집니다.
  - 상점 UI가 열려 있는 동안 기체는 **자동 선회 비행(오토파일럿)** 상태로 플랫폼 주위를 돌며, 언제든 이탈(ESC) 가능합니다.
  - 전투 모드에서는 이 3초 + UI 시간 동안 **피격 가능** (안전지대 아님) → [04번 문서](04_game_modes.md) 참조.
- **점유 인원 제한 없음** (동시 이용 가능). 단 전투 모드에서 같은 POI에 적이 있으면 경고 표시.

### POI별 기능

| POI | 아이콘 | 기능 | 소요 시간(레이스 기준 손실) |
|---|---|---|---|
| **비행기 스토어** ✈ | 청색 격납고 | 세션 내 크레딧으로 기체 교체. 3~4종 로테이션 제시 | 약 9초 |
| **무기점** 🔫 | 적색 탄약고 | 아이템 슬롯 보충/교체, 특수 무기 구매, 탄약 리필 | 약 6초 |
| **정비소** 🔧 | 녹색 렌치 | HP 회복, 부스트 게이지 즉시 충전, 경미한 성능 부품 장착 | 약 7초 |

> 시간 손실은 **우회 거리 + 감속 + UI 조작**을 합산한 목표값입니다. 밸런싱 기준: *"POI 1회 방문의 이득은 약 8초의 시간 손실과 등가여야 한다."*

### POI 배치 규칙
| 모드 | 배치 |
|---|---|
| 싱글 (거리 도전) | 5 km마다 1개, 종류는 순환(정비소 → 무기점 → 스토어). 20km 이후 밀도 감소 |
| 스피드 (레이스) | 코스당 3~5개. 최소 1개는 **주 경로에서 벗어난 위치**(딜레마 강제) |
| 전투 (배틀) | 맵당 3~4개 고정 배치, 서로 최소 2 km 이격. 서든데스 수축 시 중심부 POI만 생존 |

### POI 고도 표기 — 원 요구사항 반영
> *"지도에는 목적지를 비롯한 주요 장소들이 표기되고 그 장소의 고도가 몇인지 주요장소 표기에 함께 표기된다."*

미니맵·전체지도에서 POI 마커는 **아이콘 + 이름 + 고도**를 항상 함께 표시합니다.

```
   ┌──────────────────────┐
   │  🔧 정비소            │
   │     6,200 m   ▲ +1.4k │   ← 절대 고도 + 내 기체 대비 상대 고도
   └──────────────────────┘
```
- **절대 고도**(m)와 **상대 고도**(내 현재 고도 기준 ±)를 함께 표기합니다. 3D 공간에서 "6,200m"라는 절대값만으로는 올라가야 하는지 내려가야 하는지 즉시 판단할 수 없기 때문입니다.
- 상대 고도는 색상으로도 구분: 위쪽(▲ 청색) / 같은 층(● 백색, ±300m 이내) / 아래쪽(▼ 황색).

## 5.3 미니맵 (좌하단 상시 표시)

> 원 요구사항: *"플레이어 화면의 왼쪽 아래에 배틀그라운드와 유사한 지도"*

### 사양
| 항목 | 값 |
|---|---|
| 위치 | 화면 좌하단, 여백 24px |
| 크기 | 260 × 260 px (1080p 기준), UI 스케일 슬라이더로 70~130% |
| 형태 | **원형** (사각형 대비 3D 방향 인지에 유리) |
| 방향 | **기수 정렬(North-up 옵션 제공)** — 기본은 기수가 항상 위 |
| 표시 반경 | 2,000 m (줌 3단계: 1,000 / 2,000 / 4,000 m, `+`/`-` 또는 휠) |
| 갱신 | 15 Hz (성능 여유 시 30 Hz) |

### 미니맵 표시 요소
| 요소 | 표현 |
|---|---|
| 자기 기체 | 중앙 고정, 삼각형 화살표 |
| 목적지 / 다음 체크포인트 | 깃발 아이콘 + 거리(m) + 고도 |
| POI 3종 | 전용 아이콘 + 고도 표기 (반경 밖이면 **테두리에 클램프**되어 방향 지시) |
| 팀원 (팀전) | 팀 컬러 화살표 + 닉네임 이니셜 |
| 적 (전투) | 발각 시에만 적색 점, 3초 후 페이드 (**상시 표시 금지** — 탐색 재미 보존) |
| 팀원 핑 마크 | 닉네임 라벨 붙은 마커, 20초 유지 |
| 서든데스 공역 | 원형 경계선(청) + 다음 수축 예고선(백 점선) |
| 지형 고도 | 등고선 음영 (어두울수록 낮음) |

### 고도 표시 — 미니맵의 핵심 과제
2D 미니맵으로 3D 위치를 전달하는 것이 이 게임 UX의 최난제입니다. 3중 장치로 해결합니다.
1. **고도 테이프(Altitude Tape)**: 미니맵 **오른쪽 가장자리에 세로 막대**를 붙여 자기 고도, 목표 고도, POI 고도를 세로 위치로 표시. 한눈에 "얼마나 올라가야 하는지"가 보입니다.
2. **마커 크기/투명도**: 나보다 높으면 크고 선명, 낮으면 작고 흐리게 (원근 은유).
3. **상대 고도 수치**: 위 5.2 참조.

## 5.4 전체 지도 (`Tab` 홀드) — 배틀그라운드 방식

### 레이아웃
```
┌────────────────────────────────────────────────────┐
│  MAP  협곡 회랑           [1/3배 줌]   06:12 남음    │
│ ┌──────────────┐                   ┌─────────────┐ │
│ │              │  ╔═════════════╗  │ 고도 테이프  │ │
│ │  팀원 목록    │  ║ 중앙 30%    ║  │  12km ─     │ │
│ │  ● Kim  HP80 │  ║ 반투명 유지  ║  │   9km ─ ✈스 │ │
│ │  ● Lee  HP45 │  ║ (전방 시야)  ║  │   6km ─ 🔧  │ │
│ │  ● Park ✕    │  ╚═════════════╝  │   3km ─ ◀나 │ │
│ │              │       지도 전체     │   0km ─     │ │
│ └──────────────┘                   └─────────────┘ │
│  좌클릭: 비활성 | 우클릭: 지점 공유 | Tab: 닫기      │
└────────────────────────────────────────────────────┘
```

- 지도가 열려도 **게임은 계속 진행**되며 중앙 영역으로 전방을 볼 수 있습니다. Auto-level 보조 활성. (근거: [03번 문서 C-4](03_controls_input_spec.md))
- 마우스 드래그로 지도 이동, 휠로 줌.
- POI/목적지 마커에 **호버 시 상세 툴팁**(이름, 고도, 현재 거리, 도달 예상 시간).

### 핑 시스템 — 원 요구사항 반영
> *"지도에서 특정 지점에 마우스를 올린 후 우클릭 시 팀원들에게 지점 공유(사용자 닉네임이 마크로 표기)"*

| 항목 | 사양 |
|---|---|
| 조작 | 전체 지도 상태에서 대상 지점 호버 → `RMB` |
| 표기 | 지도·미니맵·**3D 월드 공간 모두**에 마커 표시. 라벨 = `닉네임` |
| 색상 | 핑을 찍은 플레이어의 팀 컬러(팀전) / 개인 고유색(개인전) |
| 지속 | 20초 (재핑 시 갱신) |
| 개수 제한 | 플레이어당 동시 3개, 초과 시 가장 오래된 것 소멸 |
| 스팸 방지 | 2초 쿨다운, 5초 내 4회 이상 시 8초 침묵 |
| 수신 범위 | **팀전**: 같은 팀 전원 / **개인전**: 자기 자신만(경로 메모용) |
| 부가 신호 | 핑 생성 시 팀원에게 짧은 SFX + 화면 가장자리 방향 지시 화살표 3초 |
| 고도 처리 | 2D 지도상 클릭이므로 고도는 **해당 지점 지형/POI 고도로 자동 스냅**, POI가 없으면 핑 찍은 사람의 현재 고도 사용 |

**핑 유형 확장** (`RMB` 롱프레스 시 방사형 메뉴 — v1.0 포함 권장)
- 📍 일반 지점 / ⚔ 적 발견 / 🛡 후퇴 / 🔧 정비소로 / ❓ 질문

> 텍스트 채팅과 보이스가 없어도 팀플레이가 성립하게 하는 것이 목표입니다. 다국어 유저가 섞이는 Steam 환경에서 **핑은 채팅보다 중요한 커뮤니케이션 수단**입니다.
