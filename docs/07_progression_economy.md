# 07. 성장 & 경제

## 7.1 두 개의 경제 — 반드시 분리

| | **세션 크레딧 (Credit)** | **계정 통화 (Sky Coin)** |
|---|---|---|
| 획득 | 경기 중 격추/거리/링 통과 | 경기 종료 후 정산 보상 |
| 소멸 | **경기 종료 시 전액 소멸** | 영구 보유 |
| 사용처 | 경기 중 POI 상점 (기체 교체, 아이템, 수리) | 로비 상점 (기체 영구 해금, 도색, 부품) |
| 목적 | **세션 내 의사결정** | **장기 리텐션** |

> 두 통화를 섞으면 "돈 아끼려고 상점을 안 가는" 최악의 플레이가 나옵니다. 세션 크레딧은 반드시 소멸시켜 **"이 판에서 다 써라"** 를 강제해야 POI 설계가 작동합니다.

## 7.2 기체 (Aircraft)

### 스탯 축 5개
`속도` / `가속` / `선회` / `내구(HP)` / `부스트`
— 총합을 일정하게 유지(스탯 총점 = 100)해 **상위호환 기체를 만들지 않습니다.** 무과금/신규 유저가 구조적으로 불리해지지 않게 하는 핵심 원칙입니다.

- 해금은 **레벨(플레이 시간)** 기준이며, Sky Coin으로 **단축 구매는 불가**합니다. P2W 인식은 멀티 게임 리뷰를 파괴합니다.

## 7.3 부품 (Module) — 얕은 커스터마이징

기체당 부품 슬롯 2개. 각 부품은 **명확한 트레이드오프**를 갖습니다.

| 부품 | 효과 |
|---|---|
| 경량 프레임 | 가속 +8%, 내구 −12% |
| 강화 장갑 | 내구 +15%, 선회 −8% |
| 확장 인테이크 | 최고속 +7%, 부스트 지속 −20% |
| 정밀 조준기 | 기총 탄퍼짐 −25%, 아이템 데미지 −10% |
| 자동 소화 장치 | 화염 상태 무효, 최고속 −5% |
| 확장 탄창 | 아이템 탄수 +1, 가속 −6% |

- 부품 6종은 **레벨 3부터 순차 해금**, Sky Coin으로 구매.
- **깊은 빌드 시스템은 만들지 않습니다.** 인디 규모에서 밸런싱 불가능하며, 캐주얼 타깃에게 진입 장벽이 됩니다.

## 7.4 레벨 & 경험치

| 항목 | XP |
|---|---|
| 경기 완료 (멀티) | 100 |
| 1위 / 팀 승리 | +150 |
| 격추 1회 | +25 |
| 싱글 1 km 진행 | +6 |
| 신기록 갱신 | +200 |
| 일일 첫 승리 | +300 |

- 레벨 1→30 도달 목표 시간: **약 40시간**. (레벨 30 = 마지막 기체 해금)
- 레벨 30 이후는 **프레스티지 없이 Sky Coin만 누적** — 무한 그라인딩을 만들지 않습니다.

## 7.7 도전과제 (Steam Achievements)

출시 시 **32개** 목표. Steam 도전과제는 위시리스트·플레이 시간·리뷰에 실제로 유의미하게 기여하므로 비용 대비 효율이 높은 투자입니다.

| 분류 | 예시 |
|---|---|
| 진행 | 첫 이륙 / 레벨 10 / 전 기체 해금 |
| 싱글 | 10km · 30km · 50km · 100km 도달 |
| 전투 | 누적 100격추 / 1판 5킬 / 기총만으로 격추 |
| 레이스 | 전 맵 골드 / POI 안 들르고 1위 |
| 기예 | 협곡 무피격 통과 / 부스트로 미사일 회피 / 스톨에서 회복 후 격추 |
| 소셜 | 팀전 승리 10회 / 핑 100회 / 친구와 플레이 |
| 히든 | 12,000m 도달 / 이젝션 후 낙하산 30초 생존 |
