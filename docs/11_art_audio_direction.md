# 11. 아트 & 오디오 디렉션

## 11.1 비주얼 컨셉

### 한 줄 정의
> **"청명한 세미 리얼 — 사진 같지 않지만 진짜처럼 느껴지는 하늘"**

- **포토리얼 금지.** 1인~소규모 팀이 포토리얼로 가면 AAA와 직접 비교당해 반드시 집니다.
- **완전 카툰도 금지.** 기체의 속도감과 무게감이 죽습니다.
- 목표는 그 사이: **채도 높은 하늘 + 깨끗한 실루엣 + 강한 대비.** (레퍼런스 감각: Microsoft Flight Simulator의 하늘 × Forza Horizon의 채도 × Rocket League의 UI 명료함)

### 컬러 스크립트 (맵별 지배 색)
| 맵 | 시간대 | 지배 색 | 감정 |
|---|---|---|---|
| 협곡 회랑 | 정오 | 적갈 + 청천 | 속도, 개방감 |
| 부유 도시 | 황혼 | 주황 + 보라 | 화려함 |
| 화산 지대 | 야간 | 적색 + 흑 | 위험 |
| 북극 해협 | 새벽 | 청록 + 백 (오로라) | 고요, 고독 |
| 운해 투기장 | 정오 | 백운 + 하늘색 | 명료 (전투 가독성 최우선) |
| 폭풍의 눈 | 폭풍 | 회청 + 번개 백색 | 긴장 |
| 버려진 공군기지 | 흐림 | 카키 + 회색 | 음침 |

> **전투 맵은 가독성이 미학보다 우선합니다.** 운해 투기장은 의도적으로 밝고 단순하게 만들어 적기 실루엣이 항상 명확히 보이도록 합니다.

## 11.2 기체 디자인

- **실존기 라이선스 사용 금지** (F-16 등의 형상은 제조사 상표 이슈 소지). 실루엣만 차용한 **가상 기체**로 디자인.
- 각 기체는 **3초 안에 실루엣만으로 구분** 가능해야 합니다. 멀티에서 적기 식별의 기본입니다.

| 기체 | 실루엣 특징 |
|---|---|
| Falcon | 표준 델타익, 중간 크기 |
| Dart | 극단적으로 가늘고 김, 좁은 날개 |
| Bastion | 두껍고 각진 동체, 큰 수직미익 |
| Whisper | 전진익(forward-swept), 얇음 |
| Hauler | 쌍동체, 넓은 날개 |
| Comet | 후미 대형 노즐 3개 |
| Vex | 기수 하단 대형 건포드 |
| Zenith | 매우 긴 고익, 글라이더 형상 |

### 에셋 물량 (v1.0)
| 항목 | 수량 | 조달 |
|---|---|---|
| 플레이어 기체 | 8종 (LOD 4단계) | 외주 모델링 (기체당 약 ₩120~200만) |
| 적기 AI | 3종 | 외주 |
| 파일럿 캐릭터 | 1종 + 커스텀 파츠 6 | 마켓플레이스 + 리깅 |
| 맵 | 8개 | 모듈러 키트 3세트 조합 + 마켓플레이스 활용 |
| POI 구조물 | 3종 (공용 모듈 재사용) | 자체 |
| VFX | 약 40종 | 자체 + Niagara 학습 |
| UI 아이콘 | 약 120개 | 외주 (일괄 ₩150만 내외) |

**핵심 전략: 하늘에 예산을 쓰고, 지상에 쓰지 마십시오.** 플레이어는 시간의 90%를 5,000m 상공에서 보내며, 지상 오브젝트는 대부분 실루엣으로만 인지됩니다. 지상은 마켓플레이스 에셋과 저해상도 LOD로 처리하고, 절약한 예산을 **구름·조명·기체 셰이더**에 집중합니다.

## 11.3 VFX — 속도감이 전부

비행 게임에서 "빠르다"는 느낌은 실제 속도가 아니라 **VFX와 카메라가 만듭니다.**

| 효과 | 트리거 | 강도 |
|---|---|---|
| 속도선 (Speed lines) | 속도 > 240 u/s | 속도 비례 |
| 화면 왜곡 (Radial blur) | 부스트 중 | 강 (옵션으로 감소 가능) |
| FOV 확장 | 부스트 시 90° → 105° (0.3초) | 필수 — 가장 효과적인 속도감 장치 |
| 윙팁 볼텍스 | 급선회 시 날개 끝 소용돌이 | 항상 |
| 소닉 콘 | 최고속 돌파 시 | 순간 |
| 구름 관통 | 구름 통과 시 화면 백색 페이드 + 잔류 안개 | 필수 |
| 피격 | 화면 균열, 스파크, 방향 지시 | HP 비례 |
| 화염/연기 | HP 60 이하 | 단계적 |
| 카메라 셰이크 | 피격/난기류/부스트 | 슬라이더로 0~100% |

> **모션 시크니스 대응은 선택이 아닙니다.** 비행 게임은 멀미 유발 1순위 장르이며, "멀미나서 환불"은 실제로 자주 발생하는 부정 리뷰 사유입니다. 카메라 흔들림·FOV·속도선을 각각 끌 수 있어야 합니다.

| 시점 | 기본 | 설명 |
|---|---|---|
| **3인칭 추격** | ✅ 기본값 | 기체 후상방 8m. 속도 비례로 거리 +30%까지 신축 |
| 3인칭 근접 | | 기체 크게, 몰입감 |
| 콕핏 | | 계기판 포함. 몰입 유저용 (제작 비용 발생 — 기체 8종 × 내부 모델링) |
| 리플레이 시네마틱 | | 결과 화면 하이라이트용 |

- 시점 전환: `C` 키
- **콕핏 뷰는 v1.0 범위에서 리스크 항목**입니다. 기체 8종의 내부를 모두 만들면 상당한 추가 비용이 발생합니다. → 대안: **콕핏 뷰는 인기 기체 3종만 제공**하거나 v1.1로 이연. ([14번 문서 D-05](14_open_questions.md))
- 카메라는 **기체 롤을 100% 따라가지 않습니다** (60% 추종). 완전 추종은 멀미를 유발하고 지평선 인지를 방해합니다.

## 11.5 오디오 디렉션

### 사운드 우선순위 (믹싱 기준)
1. **피격 경고 / 락온 경고** — 어떤 소리보다 크게. 생존 정보.
2. 자기 엔진 (속도 비례 피치·볼륨)
3. 무기 발사 / 히트 확인음
4. 근접 적기 통과음 (도플러)
5. 풍절음 (속도 비례)
6. 음악
7. 환경음

### 엔진 사운드 설계
- **RPM 기반 레이어 블렌딩** (idle / low / mid / high / boost) — MetaSounds로 구현
- 부스트 시 후연소 굉음 + 저역 강조
- 스톨 시 엔진음 약화 + 경고 알람 (조작 불능 상태를 소리로 먼저 알림)
- **도플러 필수**: 적기가 옆을 스칠 때의 "슉—" 소리가 이 장르의 시그니처 사운드입니다.

### 음악
| 상황 | 방향 |
|---|---|
| 메인 메뉴 | 신스웨이브 · 미드템포 |
| 방 로비 | 루프, 저자극 |
| 레이스 | 일렉트로닉 드럼앤베이스, 130~150 BPM |
| 전투 | 인더스트리얼 록, 긴장 유지 |
| 서든데스 | 레이어 추가(스트링/타악) — **적응형 전환** |
| 결과 | 승/패 분기 스팅어 |

- 트랙 8~10곡, 곡당 2~3분 루프. 조달: 로열티 프리 라이선스(Epidemic/Artlist) 또는 인디 작곡가 외주(곡당 ₩30~80만).
- **적응형 음악(수직 레이어링)** 은 서든데스에만 적용. 전면 도입은 비용 대비 효과가 낮습니다.

## 11.6 아트 파이프라인 규칙

| 항목 | 규칙 |
|---|---|
| 기체 폴리곤 | LOD0 ≤ 40k tris, LOD3 ≤ 2k |
| 텍스처 | 기체 2048², 환경 1024², UI 아틀라스화 |
| 머티리얼 | 마스터 머티리얼 5종 + 인스턴스 (드로우콜 억제) |
| 명명 규칙 | `SM_`(스태틱) `SK_`(스켈레탈) `M_`(머티리얼) `T_`(텍스처) `NS_`(나이아가라) `S_`(사운드) |
| 스케일 기준 | 1 UU = 1 cm, 기체 전장 12~18 m |
| 색약 대응 | 팀 색은 색상 + **형태(마커 모양)** 이중 부호화 |
