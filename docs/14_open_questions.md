### D-14. 레벨 곡선 산출 — `RequiredXP` vs `CumulativeXP` 열 충돌 ✅
| | |
|---|---|
| **문제** | [17 §17.7](17_data_schema.md)의 `DT_LevelCurve` 표본에서 **두 열이 서로 모순**. `누적[n] = 누적[n-1] + 필요[n]`이 성립하지 않음.<br>구간 평균 필요 XP가 그 구간 **마지막 레벨의 요구량보다 커서**(L10~16 구간 평균 3,217 > `RequiredXP[16]`=2,900) 우상향 곡선이 성립 불가. 두 열이 각각 따로 작성된 것으로 보임 |
| **선택지** | (A) `RequiredXP` 앵커 유지 + 누적 재계산 / (B) `CumulativeXP` 유지 + 필요 XP 재산출 |
| **결정** | ✅ **A — `RequiredXP` 표본 7개를 앵커로 고정하고 `CumulativeXP`를 전량 재계산** (2026-08-11) |
| **근거** | **"누적 40시간" 목표와의 정합성**이 판단 기준. `CumulativeXP` 열(총 128,000)은 약 58~64시간으로 목표를 크게 초과하는 반면, `RequiredXP` 기준 재계산 총량(**88,340**)은 약 40~44시간으로 목표에 부합. 따라서 `RequiredXP`가 신뢰할 수 있는 열 |
| **난이도 배분** | 사용자 지시(초반 쉬움 / 중반 보통 / 후반 어려움) 반영 — 초반 L2~10 평균 941 XP(총량의 9.6%) · 중반 L11~20 평균 2,775(31.4%) · 후반 L21~30 평균 5,212(**59.0%**) |
| **부수 효과** | **V8 검증 통과.** 기존에 곡선에 없던 레벨 8(`AIRCRAFT_WHISPER`)·12(`AIRCRAFT_HAULER`)가 채워짐 |
| **영향 문서** | [17 §17.7](17_data_schema.md) ✅ 반영, [`Config/DataTables/DT_LevelCurve.csv`](../Config/DataTables/DT_LevelCurve.csv) ✅ 30행 완성 |

> ⚠️ **시간 환산은 추정치입니다.** `DT_Progression` 기준 1판 ≈ 187 XP(완주 100 + 승률 25%×150 + 킬 2×25), 6분/판 → 약 2,000 XP/시간으로 계산했습니다.
> 승률·킬 수·세션 길이 가정이 전부 미검증이므로 **M1 플레이테스트 텔레메트리(`match_end`)로 반드시 교정**하십시오. 곡선의 형태는 유지하고 XP 획득량(`DT_Progression`) 쪽을 조정하는 편이 안전합니다.
