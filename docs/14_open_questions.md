### D-02. 아이템 변경 키 (`Alt` 유지 여부)
| | |
|---|---|
| **문제** | `Alt`(아이템) + `Tab`(지도) → **게임 창 최소화 사고** |
| **선택지** | (A) `Q`로 변경, `Alt`는 대안 바인딩 / (B) `Alt` 유지 + 입력 가로채기 |
| **권장** | **A** |
| **근거** | `Q`는 WASD 홈 포지션에서 손을 떼지 않고 누를 수 있고, 무기 전환의 업계 관례 위치입니다. B는 사고를 100% 막지 못합니다. |
| **영향 문서** | [03](03_controls_input_spec.md), [09](09_ui_ux_flow.md) |
| **결정** | ⬜ 미정 |

### D-03. `A`/`D`의 정의 (원안의 좌우 비대칭)
| | |
|---|---|
| **문제** | 원안에서 `D`에만 "방향 이동"이 붙어 있음 (오타로 추정) |
| **선택지** | (A) 좌우 대칭 롤 + 뱅크턴 자연 발생 / (B) 원안 그대로 비대칭 |
| **권장** | **A** |
| **근거** | 비대칭 조작은 학습 불가능하며 100% 버그로 인식됩니다. A안은 "A/D로도 방향이 바뀐다"는 원안 의도를 물리적으로 자연스럽게 충족합니다. |
| **영향 문서** | [02](02_core_gameplay.md), [03](03_controls_input_spec.md) |
| **결정** | ⬜ 미정 |

### D-04. `Space` 홀드 중 가속 처리
| | |
|---|---|
| **문제** | `W`=가속, `Space+W`=상승 → Space 홀드 중 가속 불가 |
| **선택지** | (A) 자동 스로틀 유지 / (B) `Shift` 추가 할당 / (C) Space 토글화 |
| **권장** | **A** |
| **근거** | 추가 키 없이 "속도를 유지한 채 기동"이 성립. 캐주얼 타깃에 키 개수를 늘리지 않는 것이 중요합니다. |
| **영향 문서** | [03](03_controls_input_spec.md) |
| **결정** | ⬜ 미정 |

## 🟢 프로덕션 중 결정 (M2~M3)

### D-09. 전용 서버 도입 시점
- v1.0은 리슨 서버 확정. **동접 300 이상이 90일 지속**되면 랭크전용 전용 서버 검토.
- 판단 지표: 동접, 호스트 어드밴티지 관련 리뷰 언급 빈도.

### D-10. 레이스 전용 아이템 R3(순위 도둑) 존치
- 플레이테스트에서 부정 반응이 강하면 삭제. 밸런스 데이터로 판단.
- 대안: 효과를 "앞 순위와의 거리 30% 단축"으로 완화.

### D-11. 보이스 채팅
- 권장: **미도입.** Steam·Discord로 대체 가능하고, 모더레이션 부담과 신고 처리 인력이 필요합니다.
- 대신 [05번 문서](05_map_poi_minimap.md)의 핑 시스템을 강화합니다.

### D-12. 크로스플랫폼 / 콘솔 이식
- PC 성과 확인 후 판단. 최소 **v1.0 출시 6개월 후**.
- 사전 대비: 게임패드 입력 완전 지원, 30fps 대응 가능한 물리 틱 분리는 지금부터 지켜 둘 것.
