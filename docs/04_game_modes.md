# 04. 게임 모드

## 4.0 모드 구조 요약

```
ST_AIR_POG
├── 싱글플레이
│   ├── 거리 도전 (Endless)      ← 핵심. 리더보드
│   └── 타임 어택 (코스별)        ← 리더보드 (v1.0 포함)
└── 멀티플레이 (2~10인)
    ├── 스피드 (레이스)
    │   ├── 개인전
    │   └── 팀전 (2~5팀)
    └── 전투 (배틀)
        ├── 개인전 (FFA, 라스트맨스탠딩)
        └── 팀전 (팀 데스매치 / 팀 서바이벌)
```

---

## 4.1 싱글플레이 — 거리 도전 (Endless)

### 목표
장애물과 적 전투기를 헤치며 **가장 멀리** 비행. 격추당하거나 지형에 충돌하면 종료, 도달 거리가 기록됩니다.

### 규칙
| 항목 | 값 |
|---|---|
| 시작 HP | 100 |
| 부활 | 없음 (1회 격추 = 종료) |
| 종료 조건 | HP 0 · 지형 충돌 · 자발적 종료 |
| 기록 | 최대 도달 거리(km), 격추 수, 최고 속도, 통과 POI 수 |

### 난이도 곡선 (거리 기반 무한 스케일링)
| 구간 | 특징 |
|---|---|
| 0 ~ 5 km | 튜토리얼 구간. 장애물 희소, 적기 없음. POI 1곳 |
| 5 ~ 15 km | 기본 장애물 등장. 인터셉터(T1) 2~3기 |
| 15 ~ 30 km | 기상 이변 시작. 인터셉터(T2) 편대, 협곡 구간 |
| 30 ~ 50 km | 상층 방공망. 인터셉터(T3), 대공 미사일 포대 |
| 50 km ~ | **무한 스케일링**: 5km마다 적 HP +8%, 장애물 밀도 +5%, 최대 +300% 상한 |

### 주요 장소 (POI) 활용
- `비행기 스토어` — 세션 내 획득한 **크레딧**으로 즉석 기체 교체 (더 강한 기체로 갈아타 더 멀리)
- `무기점` — 아이템/탄약 보충, 특수 무기 구매
- `정비소` — HP 전량 회복 (세션당 **횟수 무제한, 단 이용 비용이 방문마다 1.6배씩 증가**)

> **크레딧 획득**: 적기 격추 +40, 링 게이트 통과 +10, 1km 진행마다 +15.
> 이 구조가 싱글플레이를 단순 회피 게임이 아니라 **"자원 관리 로그라이트"** 로 만듭니다 — 지금 정비소에 쓸 것인가, 아껴서 20km 지점에서 더 좋은 기체를 살 것인가.

### 리더보드
- Steam Leaderboards API: `전체` / `친구` / `주간` 3종.
- 주간 리더보드는 **매주 고정 시드**로 동일한 맵이 생성되어 공정한 경쟁이 가능합니다 (프로시저럴 생성 + 시드 고정).
- 상위 기록은 **고스트 리플레이** 저장(입력 스트림 기록 방식, 용량 <50KB/판) → 다음 도전 시 반투명 고스트로 표시. 비용 대비 리텐션 효과가 매우 큰 기능입니다.

---

## 4.2 싱글플레이 — 타임 어택

- 멀티 스피드 모드의 코스를 **혼자 최단 시간**으로 주파.
- 온라인 없이도 코스를 학습할 수 있는 연습 창구이자, 동접이 낮은 시간대의 대체 콘텐츠.
- 코스당 브론즈/실버/골드/플래티넘 목표 시간 → 도전과제 및 보상 연동.

---

## 4.3 멀티 — 스피드 (레이스)

### 목표
지정된 목적지까지 **먼저 도착**. 개인전은 1위 1명, 팀전은 **팀원 순위 점수 합산**으로 승부.

### 규칙
| 항목 | 개인전 | 팀전 |
|---|---|---|
| 인원 | 2~10인 | 4~10인 (2~5팀, 팀당 2~5인) |
| 승리 조건 | 최초 결승선 통과 | 팀 점수 합 최대 |
| 점수 (팀전) | — | 1위 10 / 2위 8 / 3위 6 / 4위 5 / 5위 4 / 6위 3 / 7위 2 / 8위 이하 1 |
| 미완주 처리 | 8분 경과 시 진행 거리순 순위 확정 | 동일 |
| 격추 시 | **부활 (5초 후, 격추 지점 직전 체크포인트에서 재시작)** | 동일 |

> **레이스에서 격추는 탈락이 아니라 시간 손실**입니다. 이는 명시되지 않은 설계 공백을 메우는 결정입니다 — 레이스에서 영구 탈락은 캐주얼 타깃에게 지나치게 가혹하며, 방에 남아 지켜보게 만드는 것은 리텐션에 최악이기 때문입니다.

### 공격 요소
스피드 모드에도 **무기점 POI가 존재**하므로 전투가 가능합니다. 단 마리오카트처럼 **역전 보정**을 겁니다.
- 하위권일수록 무기점 아이템 등급이 상승 (1위: 하급 위주, 최하위: 상급 확률 3배)
- 1위에게는 후방 경고 UI 제공 (완전히 무력하지 않게)

### 코스 구조
- 길이 12~18 km, 목표 주파 시간 3.5~5분
- 체크포인트 6~9개. 통과 필수(스킵 시 역주행 판정 후 5초 내 복귀 요구)
- 분기 경로 최소 2회 — [02번 문서](02_core_gameplay.md)의 3레이어 구조를 코스마다 다르게 배치

## 4.4 멀티 — 전투 (배틀)

### 목표
아이템으로 서로를 격추. **가장 오래 살아남는 쪽**이 승리.

### 개인전 (FFA · 라스트맨스탠딩)
| 항목 | 값 |
|---|---|
| 인원 | 2~10인 |
| 목숨 | 3 (격추 시 8초 후 랜덤 안전 지점 부활, 3초 무적) |
| 승리 | 최후 1인 생존 |
| 순위 | 생존 시간 + 격추 수 |
| 시간 제한 | 6분 → **서든데스**: 맵 경계 수축(아래 참조) → 8분 하드컷 시 잔여 HP 총합 1위 |

### 팀전 (팀 서바이벌)
| 항목 | 값 |
|---|---|
| 인원 | 4~10인 (2팀 또는 최대 5팀) |
| 목숨 | 팀 공유 풀 (팀원 수 × 2) |
| 승리 | 상대 팀 전멸 또는 시간 종료 시 잔여 목숨 우세 |
| 팀 기능 | 핑 공유, 팀원 HP/위치 상시 표시, 아군 오사(FF) **없음** |

### 서든데스 — 하늘의 자기장
배틀그라운드식 축소 원리를 **3차원**으로 구현합니다.
- 6분 경과 시 **비행 가능 공역이 원통형으로 수축** (반경 축소 + 고도 상한 하강)
- 공역 밖: HP -6/s, 화면 적색 비네팅, "공역 이탈" 경고
- 30초마다 수축 단계 진행, 최종 반경 800m → 강제 교전 유도
- **이 규칙이 "가장 오래 살아남기"가 무한 도망으로 변질되는 것을 막는 유일한 장치**이므로 필수입니다.

### 전투 모드의 POI
전투 모드에도 동일한 3개 POI(`비행기 스토어` / `무기점` / `정비소`)가 존재하며, 여기서 **하이리스크 하이리턴 구도**가 발생합니다.
- POI 주변은 개활지이며 다른 플레이어에게 잘 보임 → **상점은 곧 교전 지점**
- 정비소에서 수리하는 3초 동안 **속도가 크게 느려짐** (완전 정지는 아님) → 습격 취약
- 이 설계로 POI가 자연스러운 **교전 유도 장치**가 되어, 넓은 하늘에서 서로를 못 찾는 문제(비행 배틀로얄의 고질병)를 해결합니다.

## 4.5 모드 전반 공통 규칙

| 항목 | 규칙 |
|---|---|
| 최소 시작 인원 | 2인 (1인만 남으면 대기 상태로 복귀) |
| 이탈자 처리 | 레이스: 순위에서 제외 / 전투: 즉시 격추 처리, 팀전은 팀 목숨 차감 없음 |
| 재접속 | 세션 진행 중 2분 이내 재접속 허용 (전투 모드는 잔여 목숨 유지) |
| 관전 | 전투 모드에서 탈락 시 생존자 시점 관전 가능 (이탈률 감소 목적) |
| 결과 화면 | 15초 후 자동으로 방 로비 복귀. 같은 멤버로 재시작 가능 |

## 4.6 방(Room) 규칙 — 원안 요구사항 반영

> 원 요구사항: *"카트라이더처럼 방을 개설할 때 게임 시작 전 개인전과 팀전 중 방장이 선택. 참여한 플레이어들이 모두 준비 상태에서는 모드 혹은 맵 변경 불가. 모드 또는 맵이 변경되면 플레이어들에게 토스트로 알림."*

### 상태 정의
| 상태 | 조건 | 방장 권한 |
|---|---|---|
| `OPEN` | 준비 완료자 < 전체 참가자 | 모드/맵/팀 구성 **변경 가능** |
| `LOCKED` | **전원 준비 완료** | 모드/맵 변경 **불가** (UI 비활성 + 잠금 아이콘) |
| `STARTING` | 방장이 시작 누름, 5초 카운트 | 모든 설정 불가, 취소만 가능 |
| `IN_GAME` | 경기 중 | — |

### 상세 규칙
1. **전원 준비 시 잠금**: 참가자 전원이 `READY` 상태가 되면 방 설정이 `LOCKED`으로 전환됩니다. 방장의 모드/맵 변경 UI는 즉시 비활성화되고 자물쇠 아이콘 + 툴팁("전원 준비 완료 — 설정 변경 불가")이 표시됩니다.
2. **잠금 해제**: 누구든 준비를 해제하거나, 새 플레이어가 입장하거나, 누군가 퇴장하면 즉시 `OPEN`으로 복귀합니다.
3. **변경 시 토스트**: `OPEN` 상태에서 방장이 모드나 맵을 바꾸면 **모든 참가자에게 토스트 알림**을 띄우고 **전원의 준비 상태를 자동 해제**합니다.
   - 준비 자동 해제는 원안에 없는 추가 규칙이지만 필수입니다. 준비를 누른 근거(맵/모드)가 바뀌었으므로 동의를 다시 받아야 하며, 이것이 없으면 "전투인 줄 알고 준비했는데 레이스가 시작"되는 사고가 발생합니다.
4. **토스트 문안**
   ```
   [ 게임 모드 변경 ]  전투(팀전) → 스피드(개인전)
   [ 맵 변경 ]  협곡 회랑 → 화산 지대
   [ 팀 구성 변경 ]  2팀 → 3팀
   → "설정이 변경되어 준비 상태가 해제되었습니다."
   ```
   표시 위치: 화면 상단 중앙 / 지속 3.5초 / 최대 3개 스택 / 동일 유형은 최신 것으로 갱신.
5. **방장 위임**: 방장 이탈 시 가장 오래 머문 참가자에게 자동 위임, 전원에게 토스트 알림.
6. **레이스 팀전 자동 배정**: 팀 인원 불균형 시 시작 버튼 비활성 + "팀 인원을 맞춰주세요" 안내. `자동 균등 배분` 버튼 제공.

상세 화면 설계는 [09번 문서](09_ui_ux_flow.md), 네트워크 동기화는 [08번 문서](08_multiplayer_architecture.md)를 참조하세요.
