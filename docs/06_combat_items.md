# 06. 전투 & 아이템

## 6.1 무기 슬롯 구조

```
┌──────────────────────────────────────────────┐
│  슬롯 0 : 기본 기총 (Vulcan)  — 항상 장착, 무한 │
│  슬롯 1 : 아이템 A            — 무기점/드롭 획득 │
│  슬롯 2 : 아이템 B            — 무기점/드롭 획득 │
│  슬롯 3 : 특수 (기체 고유기)   — 기체별 상이     │
└──────────────────────────────────────────────┘
        Q (또는 휠/숫자키) 로 순환 · LMB 로 사용
```

- **슬롯 0 기본 기총**은 [03번 문서 C-6](03_controls_input_spec.md)의 결정 사항입니다. 모든 모드에서 `LMB`가 항상 유효하게 만들어 조작 일관성을 확보합니다.
- 슬롯 3 **기체 고유기**는 기체 정체성을 만드는 장치이며 쿨다운제(탄약 없음)입니다.

## 6.2 기본 기총 (Vulcan)

| 항목 | 값 |
|---|---|
| 데미지 | 8 / 발 |
| 연사 | 12 발/초 |
| 유효 사거리 | 900 m (이후 데미지 감쇠, 1,400 m에서 소멸) |
| 탄속 | 2,200 m/s (거의 히트스캔에 가까우나 리드샷 필요) |
| 과열 | 2.5초 연사 시 과열 → 3초 냉각 (연사 중단 시 0.8배속 회복) |
| 탄약 | 무한 |
| 명중 보정 | 락온(`RMB`) 시 탄퍼짐 −40% |

> DPS 96. 100 HP 기체를 순수 기총으로 잡으려면 **약 1.05초의 완전 명중**이 필요합니다. 고속 기동 중 이는 매우 어렵기 때문에 기총은 "마무리·견제용", 아이템은 "결정타"라는 역할 분담이 성립합니다.

## 6.5 피격 · 격추 처리

### 데미지 파이프라인
```
발사 → (서버) 히트 판정 → 데미지 계산 → 기체 방어력 적용
   → HP 차감 → 상태 효과 판정 → 클라이언트 VFX/사운드 재생
```
- **모든 히트 판정은 서버 권위**입니다. 클라이언트는 예측 이펙트만 재생하고, 서버 판정과 다르면 이펙트를 취소합니다. ([08번 문서](08_multiplayer_architecture.md) 참조)
- **랙 보상(Lag Compensation)**: 서버는 발사자의 RTT/2 만큼 과거의 대상 위치로 되감아 판정합니다. 상한 200ms — 그 이상 지연된 클라이언트는 보상하지 않습니다(어드밴티지 악용 방지).

### 격추 연출 (약 3.5초)
1. `0.0s` 폭발 히트 + 화면 백색 플래시
2. `0.2s` 엔진 화염, 조종 불능 스핀 진입 (카메라는 기체 추적)
3. `1.2s` 캐노피 분리 → **파일럿 이젝션** (낙하산)
4. `2.0s` 기체 폭발 (유혈 없음 — [01번 문서](01_product_overview.md) 등급 정책)
5. `2.5s` 킬 크레딧 표시 → 부활 카운트다운 UI
6. `3.5s` 부활 또는 관전 전환

### 부활 규칙 (모드별)
| 모드 | 부활 |
|---|---|
| 싱글 | 없음 — 세션 종료 |
| 스피드 | 5초 후 직전 체크포인트에서 재시작, 3초 무적, HP 100 |
| 전투 개인전 | 목숨 3개. 8초 후 랜덤 안전 지점, 3초 무적, 아이템 초기화 |
| 전투 팀전 | 팀 공유 목숨 풀. 8초 후 **살아있는 팀원 근처 1,500m 지점**에 부활 (팀 재집결 유도) |

## 6.6 킬 피드 & 어시스트

- 화면 우상단 킬 피드: `킬러 [무기 아이콘] 피격자`, 4초 유지, 최대 5줄.
- **어시스트**: 격추 10초 이내 데미지 25% 이상 기여 시. 크레딧 40% 지급.
- 최종 결과 화면에 격추/어시스트/피해량/비행 거리/최고 속도 표기.

## 6.7 밸런싱 원칙

1. **어떤 아이템도 회피 불가능하지 않다.** 전설 등급 레일건조차 발사 전 0.4초의 경고음/조준선이 상대에게 보입니다.
2. **아이템 없이도 이길 수 있다.** 기총 + 기동만으로 격추가 가능해야 하며, 이는 아이템 운에 대한 불만을 흡수하는 안전판입니다.
3. **선두는 무력하지 않다.** 역전 아이템을 받되 후방 경고 UI와 회피 수단(플레어/차폐)이 항상 존재합니다.
4. **TTK(Time To Kill) 목표: 4~7초.** 너무 짧으면 조작 실력이 반영될 여지가 없고, 너무 길면 3D 공간에서 서로를 놓칩니다.
5. **모든 수치는 데이터 테이블(CSV/DataTable)로 분리**하여 코드 수정 없이 밸런스 패치가 가능해야 합니다. → [10번 문서](10_tech_stack.md)
