# 02. 코어 게임플레이

## 2.1 코어 루프

```
[활주로 탑승 연출] → [3초 카운트다운] → [이륙]
        ↓
   ┌────────────────────────────────────┐
   │  비행 (추력/기울기/벡터기동)        │
   │      ↕ 매 순간의 의사결정           │
   │  "직진할까, POI에 들를까?"          │
   │      ↓                              │
   │  장애물 회피 · 적/플레이어 교전      │
   │      ↓                              │
```

## 2.2 비행 모델 — "아케이드 세미 리얼"

### 설계 원칙
1. **추락하지 않는다.** 스톨(실속)은 있으나 조작 불능 상태로 빠지지 않고, 2초 뒤 자동 기수 회복. 하드코어 시뮬의 좌절을 제거.
2. **관성은 있다.** 방향 전환에 0.2~0.4초의 무게감을 준다. 즉각 반응은 "종이비행기" 느낌을 주고 손맛을 죽인다.
3. **속도가 곧 자원.** 급기동하면 속도를 잃고, 강하하면 속도를 얻는다. 이 교환이 유일한 "숙련 곡선".

### 물리 파라미터 (기본기 "Falcon" 기준, 튜닝 시작값)

> ⚠️ **단위 정정 (2026-08-12, D-16)**: 아래 표는 **1 UU = 1cm**(언리얼 기본 규약) 기준으로 실제 시뮬레이션에 쓰이는 값입니다. 이전 버전은 표 값을 그대로 UU/s로 써서 순항 속도가 6.48km/h(도보 속도)가 되는 오류가 있었습니다. `180×3.6=648`이 정확히 들어맞아, 원안 저자가 m/s로 값을 정하고 단위 표기만 잘못 붙인 것으로 판단해 거리 계열 값을 전부 **×100** 했습니다. 실기 테스트로 발견됐습니다. → [14 D-16](14_open_questions.md)

| 항목 | 값 | 비고 |
|---|---|---|
| 기본 순항 속도 | 18,000 u/s | 648km/h 체감 (u = 언리얼 단위 1cm) |
| 최소 속도 (스톨 임계) | 7,000 u/s | 미만 시 양력 급감, 기수 하강 |

> 위 숫자는 **손맛 튜닝의 출발점**이며, 수직 슬라이스에서 실측 후 전면 재조정 대상입니다. 어떤 문서 값도 "손맛보다 우선"하지 않습니다.

### 스톨 규칙
- 속도 < 7,000 u/s가 1.5초 지속 → **스톨 진입**: 조작 입력 감도 40%로 감소, 기수 자동 하강.
- 속도 > 10,000 u/s 회복 시 즉시 정상화. **완전한 조작 불능 구간은 만들지 않는다.**
- ⚠️ **위 수치로는 실제로 스톨에 도달하지 않습니다** (감속 하한 = 스톨 임계, 상승 페널티 < 추력 가속). M1 손맛 테스트로 재조정 필요 → [14 D-15](14_open_questions.md)

## 2.3 3차원 경로 선택 — 이 게임의 재미 축

레이스 코스는 단일 라인이 아니라 **고도별 3개 레이어**로 설계합니다.

| 레이어 | 고도 | 특징 |
|---|---|---|
| **하층 (Canyon)** | 0 ~ 1,500m | 최단 거리. 지형·건물 장애물 밀집, 실수 = 즉사 |
| **중층 (Cloud)** | 1,500 ~ 5,000m | 표준 경로. 구름 시야 방해, 적기 조우 빈도 높음 |
| **상층 (Skyport)** | 5,000 ~ 9,000m | **POI(상점)가 있는 층.** 거리 손해, 대신 보급 |

레이스에서 이론상 최속은 하층이지만 사고율이 높고, 상층은 안전하지만 우회 거리가 붙습니다.
**"POI 한 번 들르기 = 약 6~9초 손실"** 을 기준값으로 잡고, POI에서 얻는 이득이 그 손실을 상쇄할 만한지가 밸런싱의 핵심 방정식입니다.

## 2.4 장애물 카테고리

| 유형 | 예시 | 피해 | 배치 레이어 |
|---|---|---|---|
| **정적 지형** | 절벽, 아치, 송전탑, 마천루 | 충돌 시 즉사 또는 HP -60 | 하층 |
| **동적 장애물** | 회전 풍력발전기, 비행선, 크레인 | HP -40, 넉백 | 하/중층 |
| **기상** | 난기류(조작 흔들림), 뇌우(HP -10/s), 우박 | 지속 피해 | 중층 |
| **환경 함정** | 협곡 돌풍, 화산 상승기류(속도 +) | 양방향(위험/기회) | 하층 |
| **적 전투기 (싱글)** | AI 인터셉터 3티어 | 사격 피해 | 전 레이어 |
| **링 게이트** | 통과 시 속도 +8%, 3초 | 보상형 | 전 레이어 |

**설계 규칙**: 장애물은 **회피 가능함이 항상 시야에 먼저 보여야** 합니다. 카메라 기준 최소 1.2초 전 인지 가능 거리(순항 속도 기준 약 **21,600 u**, 216m)를 확보하지 못하는 배치는 반칙으로 간주하고 리젝트합니다.

## 2.5 HP / 피격 모델

- 기체 HP: 100 (기본기 기준). 기체별 60~140.
- **부위 파손 없음** (v1.0). 대신 HP 구간별 상태 효과로 긴장감 제공:

| HP 구간 | 상태 | 효과 |
|---|---|---|
| 100~61 | 정상 | — |
| 60~31 | 손상 | 연기 VFX, 최고 속도 -10% |
| 30~1 | 심각 | 화염 VFX, 최고 속도 -25%, 선회율 -15%, HUD 적색 |
| 0 | 격추 | 스핀 → 폭발 → 파일럿 이젝션 연출 |

- **정비소 POI**에서 HP 전량 회복 (모드별 비용/횟수 제한은 [06](06_combat_items.md) 참조).

## 2.6 시작 연출 (전 모드 공통)

`카트라이더` 방식의 시작 시퀀스를 그대로 채택합니다.

```
T-8s  파일럿 3인칭: 격납고에서 걸어와 기체에 탑승 (스킵 가능, 기본 스킵 ON 옵션)
T-5s  캐노피 닫힘 → 콕핏/추격 시점 전환, 활주로 정렬
T-3s  "3" (SFX: 관제탑 비프)
T-2s  "2"
T-1s  "1"
T-0   "GO!" → 입력 활성화, 스로틀 개방
```

- **입력 잠금**: T-0 이전 조작 입력은 무시. 단 **T-0.2s ~ T-0 사이 W 입력 시 "퍼펙트 스타트"** — 부스트 게이지 즉시 충전 + 초기 속도 +15%. (카트라이더 부스트 스타트 계승, 첫 판부터 "잘하는 사람"이 티나게 하는 장치)
- **너무 이른 입력(T-0.6s 이전)** 시 페널티 없음, 단순 무시. 실수 처벌은 캐주얼 타깃에 부적합.
- 멀티플레이에서는 카운트다운을 **서버 시각 기준**으로 동기화하며, 최고 RTT 플레이어 기준 +200ms 버퍼를 둡니다.
