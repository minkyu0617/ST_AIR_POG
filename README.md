## 한 장 요약 (One-pager)

- **장르**: 3D 아케이드 비행 — 레이싱 + 라스트맨스탠딩 배틀
- **플랫폼**: Steam (Windows 우선, Steam Deck 검증 목표)
- **인원**: 싱글 1인 / 멀티 2~10인
- **세션 길이**: 3~7분 (레이스 4분, 배틀 6분 목표)
- **가격 (권장)**: $12.99 / ₩16,500, 얼리 액세스 $9.99 시작
- **엔진 (확정)**: Unreal Engine **5.8** (볼류메트릭 클라우드 + 내장 리플리케이션 + Steam 연동) — D-01
- **핵심 훅**: "카트라이더의 접근성 + 배틀그라운드의 지도/핑 + 구름 위 상점 POI"

## 핵심 설계 결정 3줄

1. **구름 위 POI가 이 게임의 정체성**입니다. 레이스 중에도 `비행기 스토어 / 무기점 / 정비소`에 들르는 **경로 선택 딜레마**(시간을 쓸 것인가, 강해질 것인가)가 코어 재미이며, 모든 모드가 이 축 위에서 설계됩니다.
2. **Space는 모디파이어**입니다. `W/A/S/D` 단독은 추력·롤(기울기), `Space + WASD`는 기체 진행 방향 자체를 이동시키는 **벡터 기동 모드**로 분리합니다. (→ [03](docs/03_controls_input_spec.md))
3. **서버 권위(Server-authoritative) + 클라이언트 예측**으로 시작합니다. 10인 소규모라 P2P 리슨 서버로 원가를 0에 수렴시키되, 랭크전만 전용 서버 옵션을 남깁니다. (→ [08](docs/08_multiplayer_architecture.md))
